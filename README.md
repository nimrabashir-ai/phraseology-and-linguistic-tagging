Phraseological Analysis and Linguistic Tagging

About the Project
This project examines phraseological patterns — lexical bundles, collocations, and phrasal verbs— within two passages of an academic article on Computer Assisted Language Learning (CALL) and Mobile Assisted Language Learning (MALL). The goal was to identify recurring multi-word units in the text and tag each one with its grammatical structure.

Objective
- To locate and categorize lexical bundles, collocations, and phrasal verbs within authentic academic text.
- To assign part-of-speech tagging to each identified expression (e.g. Adjective + Noun, Verb + Noun).
- To explore how phraseology functions in academic writing on educational technology.

 Data
Two passages were selected from the article "Technology Enabled Language Learning Using CALL and MALL" by P. Sathya (2021), published in Biosc.Biotech.Res.Comm.

Methodology
Each passage was manually read and annotated by hand, color-coding three categories of phraseological units:
- Yellow — Lexical Bundles: recurring multi-word sequences (e.g. "in a fruitful way")
- Green — Collocations: words that frequently co-occur (e.g. "wireless network," "writing skills")
- Blue — Phrasal Verbs: verb + particle combinations (e.g. "points out," "get access")

Each identified expression was then grammatically tagged using standard part-of-speech notation (N = Noun, V = Verb, A = Adjective, P = Preposition, Det. = Determiner, C = Conjunction, etc.).

Results
Text 1 yielded phrasal verb, collocation, and lexical bundle examples such as "no better future" (A+N) and "in the past few decades" (P+D Art+A+Det.+N).

Text 2, a longer passage citing multiple CALL/MALL researchers, produced richer phraseological patterns, including longer lexical bundles like "paves a way for language learning in all contexts of the world" (V+Det.+N+P+N+P+Det.+N+P+Det.+N).

Overall, collocations were the most frequent category, followed by lexical bundles, with phrasal verbs appearing least often — consistent with the formal, academic register of the source text. Full tagged tables for both texts are available in the attached PDF.

Tools / Resources
- Manual close-reading and annotation
- Standard part-of-speech tagging conventions
- Microsoft Word for formatting


This project was completed as part of coursework in Language Corpora & Computer-Assisted Language Learning (CALL), exploring how phraseological analysis reveals patterns of formulaic language use in academic and technical writing.
